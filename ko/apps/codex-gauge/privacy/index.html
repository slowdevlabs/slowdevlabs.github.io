Codex Gauge 개인정보 처리방침

시행일: 2026년 7월 22일

Codex Gauge는 SlowDevLabs가 만든 macOS 메뉴 막대 유틸리티입니다. 이 문서는 앱이 정보를 처리하는 방식을 설명합니다.

Codex Gauge는 사용자의 Mac에서 로컬로 작동합니다. 계정이 필요하지 않으며 Codex 사용량 데이터를 SlowDevLabs로 업로드하지 않습니다.

수집하는 정보

Codex Gauge는 이름, 이메일 주소, 계정 정보, API 키 같은 개인 정보를 수집하지 않습니다.

앱은 사용 가능한 상태를 표시하기 위해 Mac의 로컬 Codex 환경 정보를 읽을 수 있습니다. 이 처리는 앱 기능을 위해 로컬에서 수행됩니다.

분석 및 추적

Codex Gauge 앱에는 앱 분석, 광고 SDK, 사용자 추적 기능이 포함되어 있지 않습니다.

데이터 업로드

Codex Gauge는 Codex 사용량 데이터, 로컬 환경 데이터 또는 개인 정보를 SlowDevLabs 서버로 업로드하지 않습니다.

로컬 저장

앱은 환경 설정이나 표시 설정을 사용자의 Mac에 로컬로 저장할 수 있습니다. 앱과 관련 로컬 데이터를 삭제하면 해당 설정도 제거될 수 있습니다.

지원 이메일

사용자가 이메일로 문의하는 경우, 답변과 문제 해결을 위해 사용자가 제공한 이메일 주소와 메시지 내용이 사용될 수 있습니다.

변경

앱 동작, 법적 요구사항 또는 운영 정책이 변경되면 이 개인정보 처리방침이 업데이트될 수 있습니다. 변경 시 시행일이 갱신됩니다.
