Gameplay

Short rounds, quick feedback, easy replay.

Swipe: Flags keeps the experience focused on quick decisions, clean feedback, and practice that is easy to return to.

Fast rounds

Each session stays short so it is easy to finish a round and start another one.

Clean feedback

Simple responses and clear progress help players stay focused on the flags.

Local progress

Stats and round history stay on device so the app can remain lightweight.

Features

Built for fast play and steady memory.

20-Question Sessions

Short rounds keep the game easy to start and easy to replay.

195 Countries

Personal Statistics

Voice Feedback

Privacy

Local by design.

Swipe: Flags is designed around local storage for completed game statistics, per-question game history, and app preferences. The app does not require an account, and the country and flag content is bundled so the core game can play offline.
