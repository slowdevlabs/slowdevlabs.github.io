SymbolicDrop

A quiet macOS utility for symbolic links.

SymbolicDrop keeps local symbolic link creation simple. It stays close to the file system, avoids cloud dependencies, and follows your Mac's language automatically.

The app itself follows macOS system language.

Support Privacy Terms

How it works

Select, drag, drop.

Select a file or folder. Hold ⌘ + ⇧ while dragging. Drop onto the floating target. SymbolicDrop creates a symbolic link on your Desktop.

Local symbolic link creation

Work with files and folders on your Mac without accounts, sync, or file uploads.

Desktop-friendly

Built for clear, visible destinations so you can keep track of what each link points to.

Quiet by design

Minimal surface area, minimal setup, and a support-focused presence inside the SlowDevLabs site.

What it is

Designed to sit inside the ecosystem, not above it.

SymbolicDrop is part of the SlowDevLabs brand site and stays intentionally lightweight. The website exists to support the app, explain the basic workflow, and provide clear policy pages.

Platform

It follows macOS language settings automatically.

No in-app language selector is provided for the website experience. The macOS app itself uses the system language, so the web presence stays simple and English-only.
