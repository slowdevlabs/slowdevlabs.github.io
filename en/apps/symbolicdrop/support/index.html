Support

SymbolicDrop support notes

Use these notes to understand the basic workflow, destination choices, and the macOS permission prompts that may appear while the app is managing local links.

Support email: slowdevlabs+symbolicdrop@gmail.com

Basic usage

  • Choose the source item you want to link.
  • Select the destination location on your desktop or in Finder.
  • Confirm the action and review the result in the destination folder.

Modifier keys

  • If the app shows alternate actions, use the modifier key hint shown on screen.
  • Mac keyboard shortcuts may change the available action before you confirm.
  • Follow the on-screen label for the current build of the app.

Desktop destination

  • SymbolicDrop works best when the destination is easy to inspect.
  • Use a visible desktop folder if you want a simple review path.
  • Keep the source and destination naming clear so the link stays understandable later.

Permission prompts

  • macOS may ask for Files and Folders access when the app needs it.
  • Allow access only for the folders you want SymbolicDrop to manage.
  • If permission is denied, the app cannot complete the requested file operation.
