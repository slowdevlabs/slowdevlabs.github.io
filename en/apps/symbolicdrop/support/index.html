Support

SymbolicDrop support notes

Use these notes to understand the drag workflow, the Desktop destination, and the macOS permission prompts that may appear while the app creates symbolic links.

Support email: slowdevlabs+symbolicdrop@gmail.com

Basic usage

  • Select a file or folder in Finder.
  • Hold ⌘ + ⇧ while dragging.
  • Drop onto the floating target.
  • A symbolic link is created on your Desktop.

Modifier keys

  • Hold ⌘ + ⇧ while dragging a file or folder to show the floating target.
  • SymbolicDrop uses this trigger to avoid conflicting with Finder's built-in alias behavior.

Desktop destination

  • SymbolicDrop currently creates symbolic links on your Desktop.
  • You can open the destination folder from the app settings.
  • Keep the source and destination paths clear so the link stays easy to understand later.

Permission prompts

  • macOS may ask for Files and Folders access when SymbolicDrop creates or opens links on your Desktop.
  • Allow access only for the folders you want SymbolicDrop to use.
  • If access is denied, the requested file operation may not complete.
