Website Privacy

Aviso de privacidad del sitio de SlowDevLabs

Esta página explica las prácticas mínimas de privacidad del sitio de presentación. No sustituye las políticas de privacidad de TimeTape, 돌리GO o CUE.

Última actualización: 21 de mayo de 2026 · Contacto: slowdevlabs@gmail.com

Resumen

Este sitio se usa como un hub de presentación de apps.

El sitio presenta las apps de SlowDevLabs y enlaza con sus páginas de tienda. Los datos de las apps y sus políticas se gestionan por separado en las páginas de cada app.

Analítica

Se pueden usar herramientas básicas de analítica web.

Este sitio puede usar herramientas básicas como Google Analytics para entender el tráfico y mejorar la experiencia. La analítica del sitio solo aplica a nivel web y no afecta las políticas de las apps.

Recopilación de datos

No hay cuentas, comentarios ni envíos directos.

  • El sitio no incluye un sistema de inicio de sesión o cuentas.
  • El sitio no ofrece comentarios ni publicaciones de usuarios.
  • No proporciona flujos de envío directo de datos.
  • Los datos de las apps se gestionan mediante la política y el flujo de cada app.

Cookies

Se pueden usar pequeñas cookies para analítica.

El sitio puede usar cookies estándar o tecnologías similares para analítica básica y medición del tráfico. Puedes gestionar o borrar las cookies desde la configuración de tu navegador.

Servicios de terceros

Solo analítica y enlaces a las apps.

El sitio puede referirse a Google Analytics y enlazar a App Store y a páginas de privacidad específicas de cada app. Esos servicios de terceros tienen sus propias políticas.

Políticas de privacidad de las apps

Cada app mantiene su propia política.
